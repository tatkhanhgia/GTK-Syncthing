Multi-machine file sync

Simple guide for beginners — Windows and macOS — follow the steps and you are done

1 What does this installer do?

Lets 2 or more computers share one folder. Put a file in the folder on one machine and the others automatically get it.

  • No more sending files via chat apps, email, or USB.
  • Edit a file on any machine — the rest update automatically.
Sync folder: ~/Documents/Sync (Windows: C:\Users\...\Documents\Sync)

2 Three things to know first

Existing / New machine

Existing machine = already set up sync before (e.g. your laptop).

New machine = the one you are adding now (e.g. a third PC).

Device ID

Like a unique ID for each computer — every machine has its own, never duplicated.

For two machines to talk: A must know B's ID, and vice versa. Missing either direction won't work.

Tailscale

A virtual network connecting your machines. All machines must install Tailscale and sign in with the same account.

Don't have it? Go to tailscale.com, download, and sign in.

See your Device ID: open a browser to http://127.0.0.1:8384 → find your machine → click Show ID.

3 First install (first machine)

  1. Make sure you have a Documents\Sync folder in your Windows profile (the script creates it if missing).
  2. Run: Cai-Dat-Sync.cmd
  3. When asked for "Device ID" → press Enter to skip (no other machines yet).
  4. Done. Save the "YOUR DEVICE ID" shown at the end.

4 Add a new machine

Rule: the new machine goes first, then each existing machine accepts it. Follow the order below — do not reverse it.

STEP A On the NEW machine

  1. Install Tailscale and sign in with the same account (see Section 2).
  2. Copy the whole installer folder to the new machine (USB, AirDrop, LAN).
  3. Run the install launcher:
    • Windows: Cai-Dat-Sync.cmd
    • macOS: mac/cai-dat-sync.command (after chmod +x mac/*.command if first time)
  4. When asked for "Device ID":
    • If you have an existing machine's ID nearby → paste each one → Enter. (Do this for each existing machine.)
    • If you have none → press Enter to skip; you can connect later.
  5. At the end you'll see "YOUR DEVICE ID" — this is the new machine's ID.
REQUIRED Send this "YOUR DEVICE ID" to whoever manages the EXISTING machine(s).

Check that Tailscale is running (icon in the system tray / menu bar).

STEP B On each EXISTING machine

  1. Receive the new machine's Device ID (from Step A).
  2. Run the install launcher on the existing machine → Enter:
    • Windows: Cai-Dat-Sync.cmd
    • macOS: mac/cai-dat-sync.command
  3. When asked for "Device ID": paste the new machine's Device ID → Enter. (Skip IDs you already added.)
  4. Done. Repeat on the next existing machine.

STEP C Final connection (on each machine)

  1. Open a browser: http://127.0.0.1:8384
  2. If you see "Add device" or a folder to confirm → click Add / Accept.
  3. Check that folder "Documents Sync" shows Synced.
Test: drop one file into the Sync folder on this machine — the other should get it within a few seconds.

5 Hub network / auto device sync NEW

What it does

Pick one machine to be the hub. Every other machine just runs "Join network" (menu item 6) and pastes the hub's Device ID once. New machines are then added automatically — no more pasting every Device ID manually into config.ini.

Works over Syncthing's built-in introducer: the hub introduces each machine to the others, and it keeps the shared folder up to date across all of them automatically.

Set up the hub (one time, on ONE machine)

  1. Open config.ini and set: 
    [network]
is_hub=true
auto_share=true
  2. Run Install / Add machine on the hub (menu item 1) and note its Device ID.

Join it from each other machine

  1. Install Tailscale (same account) on the new machine.
  2. Open the menu:
    • Windows: GKG-Sync.cmd
    • macOS: GKG-Sync.command
  3. Choose 6. Join network and paste the hub's Device ID.
  4. Done — the hub adds the machine to the sync folder automatically.
Prerequisite: the hub should be online when a new machine joins, and each machine runs Restart sync once. Folder "Documents Sync" should show Synced on all machines.

6 Daily use

Just put files into Documents/Sync — everything else is automatic.

Syncthing stopped? Windows: Khoi-Dong-Sync.cmd. Mac: mac/khoi-dong-sync.command.

7 Advanced: register machines in config

Optional. Use this if you want a saved list of machines so you don't paste Device IDs every time.

Open detailed instructions
  1. Open config.ini (same folder as the installer) in Notepad (Windows) or TextEdit (Mac).
  2. Add a new peer block, for example: 
    [peer.3]
name=MacBook
tailscale_ip=100.x.x.x
device_id=DEVICE-ID-HERE
  3. Save the file, run the install launcher again → Enter (skip Device ID prompts if already filled in the file).
  4. Repeat on each remaining machine.

 macOS — extra notes

  1. Install Tailscale from the Mac App Store or tailscale.com, same account as Windows.
  2. Install Homebrew (recommended) so the script can install Syncthing: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  3. First time: chmod +x mac/*.sh mac/*.command in the installer folder.
  4. Double-click mac/cai-dat-sync.command — same flow as Windows (enter existing Device IDs, copy Mac Device ID to send back).
  5. macOS may ask for network / Terminal permission the first time — choose Allow.

8 Frequently asked questions

Machines don't see each other / won't sync
Open http://127.0.0.1:8384 on both machines:
  • Is the other machine GREEN (online)?
  • Is Tailscale running on both?
  • Did you add Device IDs both ways? (Section 2)
Windows asks to allow network access for Syncthing
Click "Allow access". This step is required.
Error "cannot find path"
Extract a fresh copy of the installer. You should see Cai-Dat-Sync.cmd and README.txt in the same folder.
Sync folder in a different location on a new machine
Open config.ini (Section 6), edit sync_folder= under [local]. Leave blank = default ~/Documents/Sync.
