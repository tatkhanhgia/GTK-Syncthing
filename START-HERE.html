Sync files between your machines

Just 3 steps — no programming knowledge needed

1 Install Tailscale

Download and sign in with the same account on every machine.

Download Tailscale

2 Open the sync app

Double-click:

GKG-Sync.cmd

Select Install / Add machine and follow the instructions.

3 Send your Device ID to the other machine

After setup, the KET-QUA-CAI-DAT.html page opens — click Copy Device ID and send it to the other user(s).

The other machine then opens GKG-Sync.cmd → Install → paste the Device ID.
